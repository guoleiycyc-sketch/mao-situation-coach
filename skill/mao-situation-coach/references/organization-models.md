## Model: 从群众中来、到群众中去
### 核心命题
集体判断应从参与实践者的分散经验中提炼，再回到同一群体的行动中接受理解、执行和结果检验，并根据反馈继续修正。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第三卷《关于领导方法的若干问题》（1943年6月1日）对集中群众意见、形成领导意见并回到群众实践中检验的方法归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
抗日战争时期的组织工作跨越不同地区和基层条件，领导机关既不能脱离一线经验主观命令，也不能停留在未经整理的零散意见，需要形成能够被群众掌握并在实践中检验的工作认识。

### 关键变量
C 级现代转译：实际参与者；分散经验；意见差异；利益位置；材料覆盖；提炼标准；共同判断；反馈；行动结果；修正周期；表达、隐私和参与权保障。

### 关系逻辑
一线经验提供判断材料，比较和集中把分散材料转化为可行动的共同认识；共同认识回到实践后，其可理解性、执行差异和实际结果检验提炼是否正确。任何一环缺失，循环都会退化为命令主义、意见汇总或表面动员。

### 推演步骤
以下材料分层、异议渠道、决定权说明与反馈循环为 C 级现代转译，用于在当代组织中操作化集体认识过程。

1. 确定谁实际参与过程、承受结果，并主动覆盖不同位置和少数意见。
2. 分开记录事实经验、利益诉求、解释和建议，不以票数直接代替判断。
3. 比较共性、差异及其条件，形成可说明依据的暂时方案。
4. 用参与者能够理解和质疑的方式返回方案，明确决定权与反馈渠道。
5. 根据实际执行、未参与情况和结果修正认识，再进入下一轮。

### 适用条件
C 级现代转译：适用于判断依赖一线经验、参与者能够表达并参与反馈、组织有条件汇总差异且可以分轮调整的集体实践。

### 失效条件
C 级现代转译：当参与者表达会遭受报复、反馈渠道被权力控制、隐私和安全无法保护，或紧急风险要求专业人员立即处置时，不能用常规意见循环替代保护、独立申诉与专业判断。

### 常见误用
C 级现代转译：把一次问卷多数意见宣布为群众意见；例如管理层只收集愿意公开发言者的建议，再要求所有人服从。另一误用是反复征询却不说明如何处理意见，使参与沦为替既定决定背书。

### 关联模型
调查先于判断；感性认识到理性认识；实践—认识—再实践；领导骨干与广大群众结合；一般号召与个别指导结合

### 现代转译
C 级现代转译：在组织改进中，从实际使用者和执行者的事件记录、困难与建议出发，公开提炼出的判断和取舍，再通过试行结果、参与覆盖和异议渠道持续更新方案。

### 转译边界
C 级现代转译：这是从特定革命组织与领导实践中提炼的条件性集体认识方法，不是群体意见天然正确或历史进程必然如此的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以群众名义抹去个体权利、专业责任、少数意见、隐私和自愿参与边界。

## Model: 领导骨干与广大群众结合
### 核心命题
领导骨干应从群众实践中形成的积极分子中产生，通过同广大群众结合来组织和发展广泛主动性；随着实践和群众积极性的变化，骨干也要得到补充和更新。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第三卷《关于领导方法的若干问题》（1943年6月1日）对领导骨干与广大群众相结合这一领导方法的论述归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
1942—1943年整风背景下，领导方法需要纠正脱离群众的命令主义和只依靠少数人的狭隘工作方式，使实践中形成的积极骨干能够带动广大群众，并使群众的积极性持续发展。

### 关键变量
C 级现代转译：群众实践；实践中形成的积极分子；领导骨干；广大群众；共同任务；群众主动性；骨干与群众的联系；参与范围；实践发展；新积极分子的形成；骨干更新。

### 关系逻辑
少数积极分子从群众实践中显现并形成骨干，骨干再同广大群众结合，把分散积极性组织为共同实践；广大群众的参与又扩大实践、产生新经验和新的积极分子。只有少数骨干而没有广泛主动性，工作不能巩固和发展；骨干若不随实践更新，就会与群众变化脱节。

### 推演步骤
以下识别、连接、主动性观察与更新程序为 C 级现代转译，用于操作化骨干—群众结合关系。

1. 从共同实践中识别持续承担任务并能联系其他参与者的积极成员，不按身份预先指定骨干。
2. 检查骨干怎样同广大参与者建立双向联系，而不是只向少数活跃者分派任务。
3. 通过共同任务观察广大参与者是否形成理解、主动行动和新的经验。
4. 判断骨干的组织作用是否使这种主动性能够持续和发展，而非替群众包办。
5. 随实践变化吸收新积极成员、补充或更新骨干，使组织联系不固化。

### 适用条件
C 级现代转译：适用于存在共同的持续实践、能够从实践中辨认积极成员，并且骨干有条件联系广大参与者、组织其主动性和随实践更新的集体行动。

### 失效条件
C 级现代转译：当所谓骨干不是从共同实践中形成、只服务于自身小圈子，广大参与者没有实际行动空间，或角色永久固化而不再产生新积极成员时，骨干与群众的结合关系并未成立。

### 常见误用
C 级现代转译：把最忠于负责人、职位最高或最常发言的人固定为骨干，再把广大成员理解成被动执行者；也可能只扩大核心小组人数，却不检验其是否来自实践、能否发展广泛主动性。

### 关联模型
从群众中来、到群众中去；一般号召与个别指导结合；全面联系地认识对象；全局与局部；实践—认识—再实践

### 现代转译
C 级现代转译：在跨职能项目中，从实际协作中识别能够联系同伴的积极成员，让核心协调者持续发展更广泛的参与和新骨干。透明授权、责任监督、专业资格、任期与轮换是当代防止角色固化和滥权的 C 级安全协议，不是原著命题本身。

### 转译边界
C 级现代转译：这是从特定革命组织实践中提炼的条件性协作结构，不是少数人领导多数人天然正确或等级关系不可改变的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得借骨干角色取消民主参与、劳动权利、专业规范、问责或个人自主。

## Model: 一般号召与个别指导结合
### 核心命题
共同方向只有在典型单位或具体对象中被转化为可执行步骤、获得反馈并修正后，才能可靠扩展；个别经验也必须说明其可推广条件。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第三卷《关于领导方法的若干问题》（1943年6月1日）对一般号召和个别具体指导相结合这一工作方法的论述归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
大范围革命工作中，只有一般任务部署容易停留在口号和文件，逐一处理所有地点又超出领导能力；需要通过具体单位的深入指导取得经验，再带动和修正普遍工作。

### 关键变量
C 级现代转译：共同目标；一般要求；典型对象；当地条件；具体步骤；责任人；资源；执行反馈；代表性；推广条件；例外；修正机制。

### 关系逻辑
一般号召提供共同方向和最低标准，个别指导把方向放入具体条件并暴露执行机制。典型经验只有当因果关系、必要资源和适用差异被识别后才能推广；推广中的新反馈又应修正一般要求，而非要求所有对象机械复制。

### 推演步骤
以下试点选择、机制记录、分批推广与例外处理为 C 级现代转译，用于操作化一般号召和个别指导的结合。

1. 把一般目标写成可观察结果、底线和允许各地调整的范围。
2. 选择能揭示关键机制的具体对象，说明其典型性和特殊性。
3. 与实际执行者共同拆解步骤、资源、责任和反馈时点。
4. 记录哪些结果来自共同机制，哪些依赖该对象的特殊条件。
5. 小范围推广并比较差异，据此修改一般要求和例外处理。

### 适用条件
C 级现代转译：适用于共同任务需要跨多个团队或场景落实，能够选择具体对象深入观察，并允许先试行、再调整和分批扩展的工作。

### 失效条件
C 级现代转译：当各对象没有共同机制、试点不可代表任何其他场景、推广会造成不可逆高风险，或一般要求本身侵犯权利与专业规范时，个别成功不能为普遍执行背书。

### 常见误用
C 级现代转译：发布一句口号后把执行责任全部下推；例如要求提升客户体验却没有对象、步骤和反馈标准。另一误用是挑选资源最好的样板包装成绩，再命令条件不同的团队照抄并惩罚失败。

### 关联模型
从群众中来、到群众中去；领导骨干与广大群众结合；一般理论具体化；普遍性寓于特殊性；实践—认识—再实践

### 现代转译
C 级现代转译：推行新流程时，先给出共同目标和底线，在一两个条件不同的团队中共同试行，提炼机制、成本和例外，再分批推广并允许本地调整。

### 转译边界
C 级现代转译：这是从特定革命领导实践中提炼的条件性落实方法，不是试点成功必然能够普遍复制或一般指示天然正确的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以号召、典型或推广为由强迫参与、隐瞒失败、制造样板或突破安全与权利边界。

## Model: 统一战线
### 核心命题
在参与者利益不完全一致且力量不对等的局面中，只有经调查确认共同利益的对象、范围和期限，并同时分析联盟构成、重要差异及权力分布，才可能形成有现实基础的有限联合；各方能保持独立判断是进入联合的硬条件，但具体自主治理另由统一中的独立自主处理。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《目前抗日统一战线中的策略问题》（1940年3月11日）对不同力量、共同抗日基础、联合范围和策略关系的分析归纳；未作人民出版社1991年第二版逐字引文。联盟构成图、共同利益范围表和差异清单属于 C 级现代重构。

### 历史问题
抗日战争时期，需要分析哪些政治力量在共同抗日基础上可以联合、其社会政治构成和力量位置如何、共同范围有多大，以及不同阶级、组织和政策差异怎样限制联合，不能把所有力量当成同质整体。

### 关键变量
C 级现代转译：共同问题或事项；候选参与者；受影响但未在场者；各方利益与目标；可验证的共同利益；共同利益的对象、范围和期限；重要差异；权力、资源与依赖分布；联盟构成变化；纳入和不纳入某方的影响；联合基础的增强、缩小或消失信号；独立判断能力这一硬条件。

### 关系逻辑
历史命题针对特定民族战争和政治力量关系，不能直接复制到今天的普通合作。C 级现代重构认为，共同利益决定联合是否有基础及其可覆盖的事项，重要差异限制联合深度和期限，参与者构成及权力分布又会改变共同事项的实际含义。共同点不能抵消差异，差异也不自动否定有限共同利益；但若任何参与者不能独立核实并判断共同基础，就不得进入联合分析，权限、保留能力、责任、异议和退出等治理问题转交统一中的独立自主，不在本卡重复处理。

### 推演步骤
以下联盟基础、构成和范围分析均为 C 级现代转译。

1. 围绕同一共同问题列出候选参与者、受影响但未在场者及各自利益、目标、资源和依赖。
2. 分开记录已经证实的共同利益、共同利益覆盖的具体事项与期限，以及继续存在的重要差异。
3. 比较纳入或不纳入不同参与者会怎样改变联盟构成、力量分布、成本承担和共同事项。
4. 检查形式共同点是否被权力不对等改写，是否有关键群体被排除或被当成联合成本。
5. 先确认各方能够独立核实并判断共同基础；若该硬条件不成立，停止本卡且不形成联合结论，不得用权限或退出安排代替它。
6. 形成“可以联合的对象—共同事项—差异边界—有效期限”的暂时判断，并规定哪些利益或构成变化会使联合基础扩大、缩小或消失。

### 适用条件
C 级现代转译：适用于多个主体可能围绕同一具体事项形成有限联合，同时仍有持续差异和权力不均，并且有材料比较参与者构成、共同利益范围及其变化的情形。

### 失效条件
C 级现代转译：当所谓共同利益未经相关方确认、共同事项和期限无法界定、联盟构成及权力差异不可观察、任何一方缺少独立判断能力、差异涉及不可让渡的权利侵害，或把未参与者当作可牺牲成本时，不能判断联合基础成立。

### 常见误用
C 级现代转译：只因一句“目标一致”就宣布所有相关方应当合作，不分析共同事项究竟覆盖什么、由谁获益和承担成本；也可能把持续差异解释成不够团结，或把不同意见者归入对立阵营。

### 关联模型
全面联系地认识对象；主要矛盾；动态力量对比；客观实际约束；全局与局部

### 现代转译
C 级现代转译：跨组织合作前制作联盟基础图：候选参与者及未在场受影响者、可验证的共同利益、共同事项和期限、持续差异、资源与权力分布分别列示，据此判断联合是否有基础及其范围；只有各方具备独立判断能力后，才另行进入权限和责任治理。

### 转译边界
C 级现代转译：这是从特定抗日民族统一战线问题提炼的条件性合作分析框架，不是所有人都应被划入联盟或对立阵营的普遍政治公式；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，现代合作不得以敌我化叙事压制差异、制造排斥或取消个人和组织的合法自主权。

## Model: 统一中的独立自主
### 核心命题
在共同利益和联合范围已经成立后，各参与者仍须保持独立信息来源、明确的许可边界、必要的保留资源与行动能力，并对已同意事项承担责任，同时拥有表达异议、重新协商和安全退出的真实可能；独立自主不是拒绝协调，也不是逃避承诺。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《统一战线中的独立自主问题》（1938年11月5日）对统一战线中的独立自主、统一与独立关系的论述归纳；未作人民出版社1991年第二版逐字引文。独立信息源、权限矩阵、利益冲突披露和安全退出程序属于 C 级现代重构。

### 历史问题
抗日民族统一战线形成后，文章需要处理共同抗日与各政治力量保持自身组织、政治主张和行动能力之间的关系，防止在联合中失去独立性，也防止以独立为由破坏必要协同。

### 关键变量
C 级现代转译：已经成立的共同事项；参与者自身目标；独立信息来源与核验能力；共同许可范围；保留决定范围；禁止越权事项；保留资源、核心能力与替代通道；资源依赖；已同意责任及其证据；异议渠道；利益冲突；重新协商触发；安全退出条件与成本；单方控制和报复风险。

### 关系逻辑
历史命题发生在特定战争和政治组织关系中。C 级现代重构在统一战线已经证明联合基础与范围之后，专门检查自主治理：独立信息使判断不被单一来源控制，许可边界限制共同事项向外扩张，保留资源和能力使拒绝与退出不是空话；责任记录则防止以自主为由违背已同意事项，异议、重谈和退出机制让条件变化能够被合法处理。缺少任一关键环节，都可能使形式合作变成控制或无责任的各自行动。

### 推演步骤
以下权限划分、独立核验和退出测试均为 C 级现代转译。

1. 以前序已经成立的共同事项和范围为输入，列明每一方已经同意承担的责任及其检验方式。
2. 为每一方建立可独立取得和核验的关键信息来源，标出由单一合作方控制的盲区。
3. 划分必须共同许可、各方保留决定、需告知协商和禁止越权的事项。
4. 检查每一方是否保留履行自身目标所需的资源、核心能力和替代通道，避免依赖使许可失真。
5. 建立责任追踪、专业异议和利益冲突记录，区分正当反对与未履行已同意责任。
6. 写明重新协商的证据触发和安全退出条件，测试弱势一方拒绝额外要求、提出异议或退出时是否会遭受不当报复。

### 适用条件
C 级现代转译：适用于统一战线已经确认共同利益、参与构成和联合范围，下一步需要确保各方在履行共同责任时仍能独立核验、控制许可、保留能力并协商异议和退出的关系。

### 失效条件
C 级现代转译：当共同利益和联合范围尚未成立、一方受胁迫无法拒绝、关键事实被垄断、必要资源和能力已被完全控制、退出会招致非法报复、合作内容本身侵害权利，或所谓自主被用来逃避安全、合同和公共责任时，本模型不能正当化现状。

### 常见误用
C 级现代转译：在尚未证明共同利益时就用权限矩阵掩盖联合基础不足；也可能把独立自主解释为不共享已承诺的必要信息、不履行责任或随时单方改约。相反的误用是以“保持一致”为由要求团队放弃独立核验和专业异议、交出全部关键资源或接受越界指令。

### 关联模型
客观实际约束；调查先于判断；全局与局部；动态力量对比；客观可能性与主观能动性

### 现代转译
C 级现代转译：联合基础已经确认后，用自主治理表分别记录独立信息源、共同许可与保留权限、不可转让的核心资源和能力、已同意责任、异议渠道、重谈证据和退出保护；各方按承诺交付，同时不把信息、决定和生存能力全部交给合作方。

### 转译边界
C 级现代转译：这是从特定抗日统一战线中的政治组织关系提炼的条件性合作边界工具，不是把普通合作对象视为潜在敌手或鼓励各自为战的原则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以独立自主为名实施猜疑、控制、违约或拒绝必要问责。

## Model: 群众路线
### 核心命题
群众路线由三个必须连接的机制构成：分散经验经过比较提炼形成暂时判断，再回到共同实践检验；骨干从共同实践中形成并同广泛参与者双向联系；一般号召经由个别指导变成可检验做法，再依据个别实践的结果和适用条件推广与修正；它不是民意测验、少数人包办或样板复制。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第三卷《关于领导方法的若干问题》（1943年6月1日）对从群众中集中意见、再到群众中坚持实行并在实践中检验，以及领导骨干与广大群众、一般号召与个别指导相结合的论述综合归纳；未作人民出版社1991年第二版逐字引文。代表性检查、少数意见保护和决策审计属于 C 级现代重构。

### 历史问题
抗日战争时期的大范围组织工作需要克服脱离基层实际的命令主义，也不能把零散意见原样当成共同认识。领导方法既要从群众实践取得材料、加以集中并回到实践，又要使实践中形成的骨干同广大群众结合，还要把一般号召放入个别对象中指导、检验和推广。

### 关键变量
C 级现代转译：实际参与者与受影响者；一线事件、分散经验与利益位置；覆盖、缺席、少数与异议；事实、解释和诉求；提炼依据与暂时判断；返回共同实践的渠道；实践中形成的积极分子与骨干；骨干与广泛参与者之间的双向联系；新骨干的产生与更新；一般号召；个别指导的对象与条件；试行结果；推广条件与例外；决定权；修正周期；安全与隐私。

### 关系逻辑
历史命题处理革命组织中的领导与群众实践关系。C 级现代重构把三个原子机制连成一个回路：从群众中来、到群众中去把经验变成暂时判断并送回实践；领导骨干与广大群众结合要求骨干从这一实践中产生、组织广泛主动性，而广泛参与又产生新经验和新骨干；一般号召与个别指导结合则把暂时判断在具体对象中拆解和试行，只推广经实践支持且说明了适用条件的共同机制。缺少任一连接，都可能退化为意见汇总、少数人包办或样板命令；人数多不自动证明事实和因果，专业、安全与权利问题也不能交由简单多数决定。

### 推演步骤
以下经验—判断—实践循环、骨干—广泛参与更新以及一般—个别试行与推广程序均为 C 级现代转译。

1. 确定谁实际执行、使用和承受结果，主动寻找沉默者、少数位置和未被覆盖者。
2. 分开记录可核实事件、直接经验、解释、利益诉求和方案，说明材料来源与时效。
3. 比较共同模式、条件差异和反常证据，形成暂时判断并公开提炼依据、取舍、决定权和不能由多数表决的专业及权利边界。
4. 用参与者可理解、可质疑的方式把判断返回共同实践，记录理解、执行差异、结果和缺席影响，使它们进入下一轮经验—判断—实践循环。
5. 从共同实践中识别能够持续承担任务并联系他人的积极分子，不按职位或忠诚预先指定骨干。
6. 检查骨干是否组织了广泛参与和新的主动性，广泛参与是否又产生新经验和新骨干；若只有少数人包办，就更新联系方式与骨干构成。
7. 把暂时判断写成一般号召的共同方向和底线，选择条件可说明的具体对象，与实际参与者一起作个别指导和有边界的试行。
8. 比较个别试行的共同机制、特殊条件、失败与例外，只推广能说明适用边界的部分，并据此同时修正暂时判断、一般号召和下一轮参与结构。

### 适用条件
C 级现代转译：适用于判断高度依赖一线实践和多位置经验，存在可连续的共同实践，能够从实践中形成并更新骨干、组织广泛参与，又能把一般方向放入个别对象试行后有条件地推广的集体问题。

### 失效条件
C 级现代转译：当表达会招致报复、反馈渠道由单一权力控制、关键群体无法参与、隐私无法保护、事件要求专业人员立即处置，或决定涉及不可投票剥夺的基本权利时，不能用常规循环替代保护和专业责任。

### 常见误用
C 级现代转译：发一次问卷或看群聊多数赞成就称为群众路线；只任用固定核心组包办，不检验骨干是否来自实践、能否发展广泛主动性；或用资源最好的样板直接要求全部复制，不记录失败和推广条件。反复征询却不公开决定依据，或借“群众意见”排斥少数、专业证据和不愿公开者，同样不成立。

### 关联模型
从群众中来、到群众中去；实践—认识—再实践；领导骨干与广大群众结合；一般号召与个别指导结合；调查先于判断

### 现代转译
C 级现代转译：管理流程改进时，从不同岗位的事件和经验中形成有依据的暂时判断，再返回一线实践；从实际协作而非职位中识别能联系同伴的骨干，同时观察是否形成更广泛的参与和新骨干；把共同方向在条件不同的具体团队中个别指导和试行，只推广可说明共同机制、适用条件和例外的部分，并公开修订记录。

### 转译边界
C 级现代转译：这是从特定革命组织领导方法中提炼的条件性集体认知—实践循环，不是多数天然正确、组织可以代表所有人或投票可以替代事实和专业责任的原则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以群众名义取消个体权利、隐私、知情同意和合法异议。
