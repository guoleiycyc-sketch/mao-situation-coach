## Model: 动态力量对比
### 核心命题
力量强弱应按参与者的资源、组织、行动能力及其增减速度持续比较；当前处于劣势或优势，都不能直接推出未来结果。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《论持久战》（1938年5月）对中日双方强弱条件、消耗补充与发展趋势的综合分析归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
抗日战争初期，亡国论只看日本当时的军事优势，速胜论又把中国的潜在有利条件当成现实力量；文章需要在承认现实差距的同时说明双方力量如何随战争进程变化。

### 关键变量
C 级现代转译：参与者；当前资源；资源质量；组织和动员能力；消耗率；补充率；学习速度；支持网络；关键约束；比较时点；力量变化趋势。

### 关系逻辑
现实力量由可调用资源及其组织效率共同构成，未来力量取决于补充、消耗、学习和支持关系的净变化。局部增长若不能抵消总体消耗，就不会形成真实增强；潜力只有经过可识别的组织和转化机制，才进入力量对比。

### 推演步骤
以下力量表、净变化计算与复查时点为 C 级现代转译，用于操作化动态比较。

1. 明确比较哪些参与者、为实现哪项结果、在什么时间窗口内的力量。
2. 分别记录各方当前可调用资源、组织效率和关键限制。
3. 估算资源的补充、消耗、转化和学习方向，不只看静态存量。
4. 区分已经兑现的力量、具备转化通道的潜力和纯粹愿望。
5. 找出最可能改变相对趋势的变量，并设置下一次比较时点。

### 适用条件
C 级现代转译：适用于存在两个或多个相互影响的参与者，力量可以通过资源和行动结果观察，并且变化过程具有一定持续时间的局面。

### 失效条件
C 级现代转译：当参与者和目标边界不清、关键资源完全不可观察、结果由一次不可预测事件决定，或力量比较会掩盖不可让渡的权利与伦理义务时，不能据此形成可靠判断。

### 常见误用
C 级现代转译：把融资额、人数或声量直接等同于力量；例如竞争者融资后就断言己方必败，却不比较交付、留存和资金消耗。相反的误用是把市场潜力提前计入现有能力，忽略兑现所需时间和组织条件。

### 关联模型
全面联系地认识对象；矛盾主要方面；发展阶段；条件转化；时间作为战略变量

### 现代转译
C 级现代转译：评估业务或项目位置时，建立定期更新的力量表：可支配资源、执行效率、补充来源、消耗速度和学习结果分栏记录，用趋势而非单次排名决定是否扩大、收缩或补强。

### 转译边界
C 级现代转译：这是从特定抗日战争分析中提炼的条件性比较工具，不是强弱必按固定方向变化的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得把人简化成可支配资源或以力量优势正当化伤害、欺骗和侵权。

## Model: 客观可能性与主观能动性
### 核心命题
有效行动必须同时满足现实条件提供的可能空间和行动者把可能转成结果的组织能力；意志不能取消约束，条件也不会自动兑现机会。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对客观条件与主观指导关系的分析，以及第二卷《论持久战》（1938年5月）对客观基础、能动性和行动效果的论述综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
革命战争面对资源和力量上的现实限制，需要反对以愿望代替条件的冒险判断，也需要反对把暂时劣势看成无可行动的宿命，从既有条件中识别能够经组织争取的结果。

### 关键变量
C 级现代转译：目标；客观条件；必要资源；约束；可改变条件；行动者能力；组织协同；信息质量；行动窗口；风险；实际结果。

### 关系逻辑
客观条件规定行动的可能集合，主观能动性通过调查、组织、学习和选择改变可能性的兑现概率，并可能在边界内创造新条件。若缺少必要条件，投入意志只会增加损耗；若已有可行条件却缺少组织和行动，可能性也不会自行成为现实。

### 推演步骤
以下条件清单、可控行动与更新规则为 C 级现代转译，用于操作化可能性和能动性的关系。

1. 把目标改写为可观察结果，并列出实现它的必要条件。
2. 区分不可直接控制的约束、可以影响的条件和己方已有能力。
3. 检查客观条件是否已形成真实窗口，而非只有抽象愿望。
4. 设计能够积累能力或改变一项关键条件的可控行动。
5. 用行动结果判断应扩大投入、补足条件还是承认当前不可行。

### 适用条件
C 级现代转译：适用于目标和约束能够界定、至少部分条件可通过行动改变，并且行动风险、反馈和资源消耗可以监测的决策。

### 失效条件
C 级现代转译：当必要条件明确不存在、行动会产生不可接受的安全或伦理风险、结果主要由行动者无法影响的强制力量决定，或使用者处于需要专业救助的紧急状态时，不应以发挥能动性代替保护与支持。

### 常见误用
C 级现代转译：用主观努力责备处于结构性限制中的人；例如把缺乏无障碍条件造成的困难归咎于个人不够积极。另一误用是把客观困难当作永远不行动的借口，不区分不可控边界与可以通过学习、协作改变的条件。

### 关联模型
客观实际约束；外因通过内因起作用；条件转化；动态力量对比；实践—认识—再实践

### 现代转译
C 级现代转译：面对创业或职业机会时，先列硬约束与可改变条件，再选择一个能验证需求、补充能力或扩大支持网络的低风险动作；行动只对具体条件负责，不以意志口号替代资源核算。

### 转译边界
C 级现代转译：这是从特定革命战争实践中提炼的条件—行动框架，不是努力必然成功或人能支配一切的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得用能动性话语掩盖制度责任、受害处境、专业限制或他人自主权。

## Model: 全局与局部
### 核心命题
局部行动的价值取决于它对全局目标和关键关系的影响；全局判断也必须通过具体局部的资源、结果和相互连接来实现。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对战略全局、战役战斗局部及其相互关系的论述，以及第二卷《论持久战》（1938年5月）对全局劣势与局部优势关系的分析综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
革命战争和抗日战争需要在总体资源有限、各地情况不同的条件下安排局部行动，既防止一次局部得失动摇总体判断，也避免用抽象全局要求压过具体地区的真实条件。

### 关键变量
C 级现代转译：全局边界；总体目标；关键局部；资源分布；局部结果；相互依赖；传导路径；协同关系；时间顺序；机会成本；风险底线。

### 关系逻辑
全局为局部确定方向和评价尺度，局部通过结果、资源消耗和连锁影响改变全局。局部成功只有能保存、复制、连接或改善总体条件时才形成战略价值；全局安排若不能落实到有条件的局部，就只是抽象要求。

### 推演步骤
以下贡献比较、机会成本、资源重配和权利检查为 C 级现代转译，不作为历史战略命题的直接原文程序。

1. 界定全局的对象、时间范围和必须守住的总体目标。
2. 列出各局部掌握的资源、限制及其对全局的连接方式。
3. 比较局部行动对总体目标的直接贡献、连锁影响和机会成本。
4. 识别需要集中支持的关键局部，以及不能被牺牲的安全和权利边界。
5. 根据局部反馈更新全局安排，并说明资源调整理由。

### 适用条件
C 级现代转译：适用于项目由多个相互依赖的地区、团队、产品线或阶段构成，资源需要跨局部分配，并且存在可共同评价的总体目标。

### 失效条件
C 级现代转译：当所谓全局没有正当且明确的共同目标、局部之间实际互不相关、中央位置无法获得真实反馈，或局部承担不可逆伤害却没有参与权时，不能用全局名义作机械取舍。

### 常见误用
C 级现代转译：用顾全大局压制一线报告和少数人的合法权益；例如为赶进度隐瞒某地安全缺陷。相反也可能因一个试点数据好就立即全量推广，未检查它是否能在其他局部复制或是否透支共同资源。

### 关联模型
全面联系地认识对象；主要矛盾；动态力量对比；时间作为战略变量；空间作为战略变量

### 现代转译
C 级现代转译：管理多团队项目时，用总体目标、局部贡献、依赖关系和机会成本共同排优先级；每个试点既要有局部结果，也要说明它怎样改善或检验整体方案。

### 转译边界
C 级现代转译：这是从特定战争指挥问题中提炼的条件性尺度工具，不是抽象整体天然高于个体和局部的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以全局利益取消知情、安全、程序正义和基本权利。

## Model: 时间作为战略变量
### 核心命题
时间会通过消耗、积累、学习和窗口变化重塑力量关系，因此等待、加速和行动顺序都必须由可验证的时间机制决定，而非由耐心口号决定。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《论持久战》（1938年5月）对战争持续、力量消长、阶段推进和有利条件积累的分析归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
抗日战争初期需要说明为何不能以当前强弱推断结局，也不能期待迅速取胜；持续时间只有在敌我消耗、国内外支持和自身组织等条件发生有利变化时才具有战略意义。

### 关键变量
C 级现代转译：时间窗口；资源消耗率；补充率；学习周期；关系积累；机会衰减；反馈延迟；行动顺序；阶段门槛；不可逆损失检查；停止条件。

### 关系逻辑
经过时间，各方资源和能力按不同速度积累或衰减，行动先后还会改变后续选项。若有利变量的净积累快于损耗，延长时间可能改善局面；若机会持续关闭或损失不可逆，等待会恶化局面。时间本身不产生优势。

### 推演步骤
以下时间账本、顺序安排、行动触发与停止条件为 C 级现代转译，用于操作化时间机制。

1. 明确决定所处的截止窗口、反馈延迟和不可逆时点。
2. 分别列出随时间增长、消耗和保持不变的关键变量。
3. 比较等待一段时间后，各方净力量和可选行动会怎样变化。
4. 排列必须先做、可以并行和应延后的行动及其依赖关系。
5. 设置继续等待、提前行动和停止投入的可观察条件。

### 适用条件
C 级现代转译：适用于结果受积累、消耗、学习或时机影响，能够观察变量随时间变化，并且行动顺序仍有调整空间的过程。

### 失效条件
C 级现代转译：当存在必须立即处置的安全风险、机会在极短时间内随机消失、关键变化不可监测，或等待本身持续侵害他人权益时，不能把时间当作可自由运用的变量。

### 常见误用
C 级现代转译：把坚持足够久当作成功原因；例如产品长期没有留存仍以市场教育需要时间为由拒绝设置停止条件。另一误用是只为追求速度而压缩必要验证、恢复或协商时间，造成不可逆损失。

### 关联模型
动态力量对比；发展阶段；条件转化；全局与局部；空间作为战略变量

### 现代转译
C 级现代转译：对长期项目建立时间账本：每月哪些能力在增长、哪些资源在燃烧、哪些机会在关闭，以及下一项行动依赖什么；用净变化和截止条件决定等、快做或停止。

### 转译边界
C 级现代转译：这是从特定持久战争分析中提炼的条件性动态工具，不是时间自动站在任何一方或坚持必胜的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以长期主义为由拖延求助、容忍伤害、无限投入或逃避责任。

## Model: 空间作为战略变量
### 核心命题
行动范围、位置、距离和资源分布会改变接触成本与局部力量密度，因而可通过选择空间边界形成可验证的局部条件，而不能把扩张范围本身当作优势。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对战场范围、根据地和局部力量配置的分析，以及第二卷《论持久战》（1938年5月）对中国地域条件、运动空间和局部优势的论述综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
中国革命战争与抗日战争在地域广、资源分散和总体力量不利的条件下，需要分析怎样利用地域差异、回旋范围与局部集中改变具体接触条件，而不是机械固守所有地点。

### 关键变量
C 级现代转译：空间边界；位置；距离；资源密度；交通与沟通成本；覆盖范围；节点；依赖网络；进入与退出成本；局部优势；外溢影响。

### 关系逻辑
空间分布决定资源能否及时汇集、信息能否传递以及参与者在何处发生接触。缩小范围可能提高资源密度和学习速度，扩大范围可能获得新资源但增加协调成本；空间选择的价值取决于它对目标和全局联系的实际影响。

### 推演步骤
以下空间地图、成本比较、最小范围和扩展规则为 C 级现代转译，用于操作化空间配置。

1. 标出目标发生在哪些区域、渠道、团队或用户群，而非只画物理地点。
2. 记录资源、能力、需求和关键节点在各空间的分布。
3. 比较进入、覆盖、协调和退出各空间的成本与风险。
4. 找出能够形成相对资源密度并产生清晰反馈的最小范围。
5. 检查局部选择对其他区域和总体目标的外溢影响，再决定扩展、保持或退出。

### 适用条件
C 级现代转译：适用于资源和需求在地点、渠道、组织单元或用户群之间分布不均，且行动范围可以选择或分阶段扩展的情形。

### 失效条件
C 级现代转译：当空间差异与结果无实质关系、关键对象无法分区、跨区外溢无法控制，或缩小范围会形成歧视、排斥和不可接受的服务缺口时，不能以空间配置替代正当责任。

### 常见误用
C 级现代转译：把占据更多市场、城市或渠道当作实力增长；例如团队尚无交付能力就同步进入多个地区，导致资源稀释。也可能只追求局部指标而把成本和风险转嫁给未被纳入地图的人群。

### 关联模型
全局与局部；动态力量对比；全面联系地认识对象；时间作为战略变量；客观可能性与主观能动性

### 现代转译
C 级现代转译：把空间理解为可选择的业务边界：先在需求集中、协作成本可控且能获得有效反馈的用户群或区域验证机制，再依据资源密度与外溢风险决定是否扩张。

### 转译边界
C 级现代转译：这是从特定革命战争地域问题中提炼的条件性配置工具，不是占有更多空间必然更强或任何场景都应争夺地盘的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得借空间优化实施歧视、越界控制、隐私侵犯或责任转嫁。

## Model: 持久战
### 核心命题
持久战不是单纯坚持，而是在力量会动态变化的长期过程中，一面保存并发展核心力量，一面促成有利条件积累、降低问题或对方的持续作用能力，并依据停止与修订信号不断改变行动。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《论持久战》（1938年5月）对中日双方力量消长、战争持久性、阶段变化及主动行动的综合分析归纳；未作人民出版社1991年第二版逐字引文。将其写成资源账本、问题消耗和停止规则属于 C 级现代重构，不是原著术语或原有程序。

### 历史问题
抗日战争初期，文章针对亡国论和速胜论，分析敌强我弱等现实条件及其不平衡、变化和相互作用，说明战争为何可能持久、力量为何可能经过保存、消耗、补充与发展而改变。

### 关键变量
C 级现代转译：目标与过程边界；全面联系地认识对象所需的参与者、资源、约束和依赖的整体关系；全局与局部所需的全局目标、局部任务与传导路径；空间作为战略变量所需的行动范围、资源分布与回旋余地；双方或问题力量；核心力量；补充率；消耗率；学习和组织速度；外部支持；有利条件的积累机制；问题或对方作用能力的消耗机制；时间窗口；不可逆损失；停止、修订与退出信号；仅在集体行动存在时调用从群众中来、到群众中去所需的一线经验、暂时判断、共同实践与反馈渠道。

### 关系逻辑
历史命题处理的是特定战争中力量随时间和行动发生的条件性消长，并不等于时间自然带来胜利。C 级现代重构首先用全面联系地认识对象检查参与者、资源、约束和外部支持，避免只盯单一强弱；再用全局与局部判断局部行动能否保存、连接并改善全局，用空间作为战略变量选择能够形成资源密度、取得反馈且保留回旋余地的行动范围。只有核心力量得到保存和发展、有利条件持续兑现、主要问题或对方的作用能力被削弱，长期投入才可能改善局面；若净损耗上升、关键窗口关闭或原因果判断被否定，就必须修订或停止。若情境确实涉及集体行动，才调用从群众中来、到群众中去，使分散经验经过提炼回到共同实践；个人决策或不存在共同实践时不得附会这一组织机制。

### 推演步骤
以下长期账本、消耗机制和停止规则均为 C 级现代转译。

1. 界定长期过程、希望改变的结果、参与者和不可逾越的安全与权利边界。
2. 用全面联系地认识对象画出关键参与者、资源、约束、依赖和外部支持，主动寻找会推翻单线叙事的遗漏关系。
3. 用全局与局部说明候选局部怎样保存核心力量、积累可转移结果并改善全局；没有传导路径的局部成绩不计入持久机制。
4. 用空间作为战略变量比较行动范围、资源密度、接触和协调成本及退出余地，选择最小且可回旋的有效空间，而非全面铺开。
5. 建立动态力量表，分别记录核心力量的存量、补充、消耗、学习和支持来源；说明时间怎样积累有利条件、行动怎样降低问题持续发生的能力，不能只写“再坚持一段时间”。
6. 只有在共同实践真实存在时，才用从群众中来、到群众中去取得分散经验、形成暂时判断并返回集体行动检验；否则跳过此步。
7. 选择兼顾保存、积累、反馈和有效消耗的阶段性行动，设置继续、扩大、收缩、改路和退出信号；每轮按净变化复查，出现不可逆损失、净恶化或机制失效即调整。

### 适用条件
C 级现代转译：适用于过程具有可观察的持续时间，力量、能力或问题强度会因行动而变化，核心资源能够保护和补充，并且可设置分段反馈与退出条件的局面。

### 失效条件
C 级现代转译：当延长过程只增加不可逆伤害、核心力量无法补充、所谓有利条件没有兑现机制、问题强度不受行动影响、窗口即将关闭，或存在必须立即处理的安全和法律风险时，不得建议持久投入。

### 常见误用
C 级现代转译：把熬得更久当成策略；例如产品长期没有留存、现金持续下降，却以“长期主义”为由拒绝复盘。另一误用是只计算对方或问题的消耗，不计算自身核心能力、信任与健康的损失，也不设退出线。

### 关联模型
全面联系地认识对象；全局与局部；空间作为战略变量；动态力量对比；时间作为战略变量；客观可能性与主观能动性；条件转化；发展阶段；从群众中来、到群众中去

### 现代转译
C 级现代转译：为长期项目先画整体关系图，再核对每个局部怎样连接全局，并选择资源密度高、反馈清楚且可退出的行动空间；随后建立双向变化表，记录哪些能力正在保存和增长、哪些有利条件正在积累、核心问题的发生能力是否下降、自身代价是否可恢复。仅当多人共同实践构成行动机制时，才增加一线经验—共同判断—返回实践的组织循环；按预设证据选择继续、调整、缩小或停止，而不是把坚持本身当成成果。

### 转译边界
C 级现代转译：这是从特定抗日战争战略分析中提炼的条件性长期行动框架，不是坚持必胜、弱者必然转强或消耗他人天然正当的永恒规律；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以持久为由容忍伤害、操纵关系或无限投入。

## Model: 战略防御—相持—反攻
### 核心命题
战略防御、相持和反攻是由主要关系、力量结构与行动能力界定的历史阶段，不是按日历自动到来的三段时间；阶段转移必须由可观察的关系变化和转折条件支持。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第二卷《论持久战》（1938年5月）对抗日战争战略防御、战略相持和战略反攻三个阶段及其力量条件的分析归纳；未作人民出版社1991年第二版逐字引文。将阶段转译为当代项目的门槛、指标和退出规则属于 C 级现代重构。

### 历史问题
文章需要说明抗日战争不会由初期敌强我弱直接跳到胜利，而会随占领、抵抗、消耗、发展及国际国内条件变化呈现不同战略地位和任务；三阶段是对特定战争可能进程的条件性判断。

### 关键变量
C 级现代转译：过程边界；当前主导关系；双方力量及趋势；核心能力保存程度；行动空间；关键任务；阶段进入条件；阶段退出条件；反向转移信号；证据时点；安全和权利底线。

### 关系逻辑
历史三阶段由战争中攻守地位和力量关系的变化区分，不由经历时长命名。C 级现代重构只借用“稳住—僵持与积累—扩大主动结果”的关系结构：只有力量趋势、行动能力和关键条件跨越事先说明的门槛，任务才可转换；关系退化时也可能回到保护和重建能力。

### 推演步骤
以下阶段门、转移证据和回退机制均为 C 级现代转译。

1. 用当前主导关系和可观察结果描述所处状态，不用项目月份或主观感受命名阶段。
2. 为每个候选阶段写明中心任务、必须保存的能力与不可承担的损失。
3. 分别规定进入下一阶段所需的力量、组织、反馈和外部条件。
4. 检查这些条件是否已真实兑现，并寻找关系仍未改变的反证。
5. 达到门槛才调整任务和资源；未达到则继续补条件或修订阶段判断。
6. 设置退回、停止或重新调查的信号，防止只许前进、不许纠错。

### 适用条件
C 级现代转译：适用于持续过程确有不同关系状态，阶段间任务和资源配置不同，并能取得力量、结果和转折条件证据的项目或组织变化。

### 失效条件
C 级现代转译：当过程没有可辨识的阶段关系、阶段只按时间或融资轮次划分、转折无法观测、外部事件可瞬间终止过程，或使用阶段叙事掩盖明确失败与伤害时，本模型失效。

### 常见误用
C 级现代转译：把第一季度称为防御、第二季度称为相持、第三季度称为反攻，却没有任何力量或关系变化证据；也可能见到一个好指标就宣布转段，忽略核心能力尚未保存、其他关键条件仍在恶化。

### 关联模型
发展阶段；动态力量对比；矛盾主要方面；条件转化；时间作为战略变量

### 现代转译
C 级现代转译：给转型项目设置状态门而非日期表：先稳住关键交付和现金流，再以核心指标停止恶化、学习机制形成和净力量改善判断是否进入积累状态，最后以可复制能力和风险可控判断是否扩大行动；任何阶段都保留回退条件。

### 转译边界
C 级现代转译：这是从抗日战争三个战略阶段中提炼的条件性分段工具，不是所有事业必经三阶段或最终必然反攻的历史公式；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得把普通协作中的调整包装成攻守对抗。

## Model: 整体劣势中的局部优势
### 核心命题
总体处于劣势时，可以在与全局相连且边界明确的局部，通过选择范围、时机和资源密度形成相对优势；这种局部杠杆必须可保存、可退出并改善全局，不能成为孤注一掷。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对战略劣势与战役、战斗优势关系的分析，以及第二卷《论持久战》（1938年5月）对总体强弱和局部优势的论述综合归纳；未作人民出版社1991年第二版逐字引文。局部试点、可逆投入和退出阈值属于 C 级现代重构。

### 历史问题
革命战争和抗日战争面临总体力量不足，需要说明怎样在具体时间、地点和行动中改变局部力量对比，同时避免把一次局部得失误作全局胜负。

### 关键变量
C 级现代转译：总体目标与劣势；候选局部；局部资源密度；对方或问题强度；时间窗口；空间和对象边界；局部—全局传导路径；可逆性；撤出成本；核心力量风险；复制条件。

### 关系逻辑
历史命题区分战略层面的总体劣势与具体行动中的局部优势。C 级现代重构认为，局部优势只有在投入相对集中、反馈清楚、损失可承受且结果能保存或传导到全局时才是杠杆；若必须押上全部核心资源、没有退出路径或局部成功不能改善总体条件，就不是可靠优势。

### 推演步骤
以下局部选择、杠杆检验和风险上限均为 C 级现代转译。

1. 明确总体劣势究竟表现在哪些资源、能力和关系上。
2. 列出若干可缩小的用户、场景、流程或区域，比较其中的相对资源密度和问题强度。
3. 说明局部结果如何保存、复制或改变全局，而非只制造漂亮数字。
4. 为局部行动设置投入上限、撤出条件和核心能力保护线。
5. 选择最小可行局部验证机制，取得反馈后再决定保持、扩大或退出。
6. 复查局部投入是否正在抽空其他关键环节或把风险转嫁给他人。

### 适用条件
C 级现代转译：适用于总体资源不足但分布不均，存在可选择的范围和时机，局部结果能够观测并可能连接全局，且行动可分段、可退出的情形。

### 失效条件
C 级现代转译：当资源无法形成任何相对密度、局部与全局没有传导路径、试点成本不可逆、失败会摧毁核心能力，或局部优势依赖侵害他人权益时，不能据此投入。

### 常见误用
C 级现代转译：把“局部优势”理解为把所有现金和人员押在一次发布上；也可能挑选最容易成功却与主问题无关的样板点，以局部漂亮指标掩盖总体关系继续恶化。

### 关联模型
全局与局部；空间作为战略变量；动态力量对比；客观实际约束；客观可能性与主观能动性

### 现代转译
C 级现代转译：资源弱势团队可在需求集中、交付能力匹配且反馈周期短的细分场景形成局部密度；先用有限预算验证留存和复制条件，只有结果能转化为能力、现金或可靠知识时才扩大，始终保留撤出余量。

### 转译边界
C 级现代转译：这是从特定战争中总体与局部力量关系提炼的条件性杠杆工具，不是弱势者应冒险豪赌或局部成功必然翻转全局的法则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得用局部优势合理化欺骗、排斥或伤害。

## Model: 集中优势力量
### 核心命题
资源有限时，应围绕一个有全局价值、条件相对有利且结果可检验的具体任务，提高局部可调用力量密度；集中必须保留必要能力、风险余量和退出路径，不是把全部资源一次押上。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对集中兵力与分散兵力关系的分析，以及第四卷《集中优势兵力，各个歼灭敌人》（1946年9月16日）对集中兵力处理具体作战目标的论述综合归纳；未作人民出版社1991年第二版逐字引文。任务筛选、风险预算和组合停止条件属于 C 级现代重构。

### 历史问题
革命战争在总体力量受限和任务众多的条件下，需要避免平均分散兵力，在具体作战中形成相对优势，并把局部结果服务于整个战争进程。

### 关键变量
C 级现代转译：总体目标；候选任务；任务价值；必要资源；当前可调用力量；相对密度；协同成本；机会成本；最低保留能力；风险预算；完成标准；退出与重配条件。

### 关系逻辑
历史命题讨论特定军事行动的力量配置。C 级现代重构只保留有限资源不应平均摊薄的配置逻辑：集中能提高协同和完成概率，但价值取决于任务与全局的连接、相对条件和可承受代价；越过最低保留能力或把不可逆失败风险集中到一点，就由杠杆变成鲁莽押注。

### 推演步骤
以下任务组合、保留线和重配规则均为 C 级现代转译。

1. 明确当前全局目标及必须持续维持的底线能力。
2. 比较候选任务的全局价值、必要资源、完成窗口和结果可验证性。
3. 选择一个能够形成相对资源密度的中心任务，同时写明暂缓事项。
4. 先扣除安全、合规、基本运营和恢复余量，再确定可集中资源上限。
5. 设置完成、失效、超支和退出标准，按反馈分批投入而非一次押满。
6. 完成或触发停止条件后及时释放、补充和重配力量。

### 适用条件
C 级现代转译：适用于任务之间争夺同一有限资源、至少一个任务具有较高全局价值和相对可行条件，并能设定分批投入、结果标准与退出机制的局面。

### 失效条件
C 级现代转译：当多个任务都属不可暂停的安全或法定义务、任务价值与完成机制不清、集中会摧毁基本运营、失败不可承受，或资源瓶颈实际来自不可替代的专业能力时，不宜机械集中。

### 常见误用
C 级现代转译：把集中理解为全员无期限加班、取消所有维护和押上全部现金；也可能只因领导偏好就称某任务为重点，既不比较机会成本，也不设完成和撤出条件。

### 关联模型
全局与局部；动态力量对比；空间作为战略变量；客观可能性与主观能动性；客观实际约束

### 现代转译
C 级现代转译：季度资源紧张时，先保留安全、交付和现金缓冲，再把可调整资源分批投入一个与总体结果直接相连的瓶颈任务；以里程碑决定追加或撤回，并公开被延后事项及其代价。

### 转译边界
C 级现代转译：这是从特定战争力量配置中提炼的条件性资源配置工具，不是集中越多越好、服从重点天然正确或结果可以不计代价的原则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以集中之名强迫劳动、突破专业规范或剥夺基本保障。

## Model: 积小胜为大胜
### 核心命题
局部结果只有能够重复、保存并相互连接，持续改善力量结构和全局条件时，才可能积累为更大的结果；小胜不是数量堆积，也不是以短期指标代替结构变化。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）、第二卷《论持久战》（1938年5月）关于通过具体行动保存、消耗和发展力量的分析，以及第四卷《集中优势兵力，各个歼灭敌人》（1946年9月16日）对局部作战结果与全局进程关系的论述综合归纳；未作人民出版社1991年第二版逐字引文。复利账本、复制检验和领先指标属于 C 级现代重构。

### 历史问题
在总体力量不利、难以一次解决全局问题的战争条件下，需要通过一系列相互关联的局部行动改变力量关系，同时防止以孤立战果或一时得失替代战略判断。

### 关键变量
C 级现代转译：全局目标；小胜定义；结果真实性；可重复机制；保存方式；连接路径；能力增量；资源回收；学习增量；后续选择；累积成本；负外溢；停止与升级条件。

### 关系逻辑
历史命题强调局部行动在长期力量变化中的作用。C 级现代重构认为，小胜只有转化为可保留的能力、资源、信任或知识，并降低下一步成本、扩大后续选择时才发生积累；彼此无关的漂亮指标、靠透支取得的成果或不可复制偶然事件不会自动构成大胜。

### 推演步骤
以下累积链、复制检验和净收益核算均为 C 级现代转译。

1. 从全局目标倒推一项可验证、可在短周期完成的小结果。
2. 说明该结果怎样被保存为能力、资源、关系或可复用知识。
3. 检查它是否降低下一步成本、提高成功率或打开新的行动空间。
4. 在不同对象或时间重复验证机制，区分偶然结果与可复制关系。
5. 累计收益同时累计成本、伤害和机会损失，计算真实净变化。
6. 达到结构性门槛才扩大；若小胜不再连接全局或靠持续透支维持，则调整或停止。

### 适用条件
C 级现代转译：适用于总体目标可拆成相互衔接的阶段结果，小步行动风险可控，成果能够保存和复用，并有足够反馈周期检验累积机制的过程。

### 失效条件
C 级现代转译：当局部结果无法保存或连接、每次都从零开始、累积成本高于收益、关键窗口只允许一次性行动，或所谓小胜建立在转嫁伤害和虚假指标上时，本模型失效。

### 常见误用
C 级现代转译：把粉丝数、会议数或短期订单逐月上涨直接当作大胜将至，却不检查留存、交付和现金；另一误用是为了连续报喜只选择容易完成的事项，使真正制约全局的关系长期不变。

### 关联模型
全局与局部；时间作为战略变量；动态力量对比；实践—认识—再实践；条件转化

### 现代转译
C 级现代转译：把每轮试点的结果写入累积账本：是否留下可复用流程、提高留存、补充现金、缩短反馈或扩大可靠合作；只有这些增量能连接下一轮并逐步改变中心约束，才扩大投入。

### 转译边界
C 级现代转译：这是从特定战争中局部结果与全局力量变化关系提炼的条件性累积工具，不是任何小成果都必然通向成功或可以用战果逻辑衡量日常关系；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以追求胜利侵犯诚信、安全和自主权。

## Model: 主动性、灵活性与计划性
### 核心命题
主动性是在客观可能空间内争取行动选择，灵活性是随具体条件和反馈改变方法，计划性则保持目标、资源、顺序和检验标准的协调；三者必须结合，不能把冲动、随意或僵化分别冒充行动能力。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第二卷《论持久战》（1938年5月）对战争中的主动性、灵活性和计划性的论述，以及第一卷《中国革命战争的战略问题》（1936年12月）对主观指导与客观条件关系的分析综合归纳；未作人民出版社1991年第二版逐字引文。当代滚动计划、决策权限和复盘节奏属于 C 级现代重构。

### 历史问题
抗日战争和革命战争面对敌我力量、地域与时机不断变化，需要既反对消极被动，又反对脱离客观条件的冒险和没有全局安排的临时应付，使行动选择与战略目标保持联系。

### 关键变量
C 级现代转译：目标；客观约束；可选行动；决策权限；信息时效；资源与顺序；关键依赖；反馈周期；变更范围；计划假设；风险上限；升级、暂停和停止条件。

### 关系逻辑
历史命题说明主观指导必须在实际战争条件中争取主动、灵活处置并服从计划。C 级现代重构认为，计划给主动行动方向和资源边界，灵活调整使计划不被旧假设绑住，主动性则把可行选择落实为行动；缺一会分别退化为无序冲动、机会主义变化或僵化执行。

### 推演步骤
以下滚动计划、权限边界和变更记录均为 C 级现代转译。

1. 写明目标、关键约束、资源上限、行动顺序和预期结果。
2. 列出当前可争取的选择，并区分已有权限、需协商事项和不可越过的边界。
3. 标明计划依赖的事实假设及其复查时点。
4. 给执行者保留针对当地条件调整方法的范围，同时明确需升级的风险。
5. 用反馈比较预期与实际，记录为何保持、变更、暂停或停止。
6. 更新计划时维持目标与资源的一致性；目标本身失效则公开重定，而非暗中漂移。

### 适用条件
C 级现代转译：适用于目标和基本约束明确、执行环境会变化、团队能够获得反馈，并且存在一定行动选择和滚动调整空间的项目。

### 失效条件
C 级现代转译：当行动受紧急安全规程或法定义务严格限定、信息完全不足、参与者没有真实权限、调整代价不可逆，或目标本身不正当时，不能以灵活和主动替代专业与权利边界。

### 常见误用
C 级现代转译：把频繁改方向称为灵活，却没有新证据和变更记录；把抢先行动称为主动，却不核算条件；或把按过期甘特图执行称为计划性，明知关键假设已被事实否定仍不调整。

### 关联模型
客观可能性与主观能动性；客观实际约束；全局与局部；动态力量对比；实践—认识—再实践

### 现代转译
C 级现代转译：采用滚动计划：领导层明确目标、资源和风险线，执行者在授权范围内按现场反馈调整方法，每个复查周期公开假设变化、资源影响和下一步选择，使自主行动与整体协调同时存在。

### 转译边界
C 级现代转译：这是从特定战争指挥问题提炼的条件性行动协调框架，不是个人意志可以突破客观限制、灵活等于无规则或计划要求无条件服从的原则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得用主动和计划为越权、强迫或隐瞒风险辩护。

## Model: 保存和发展核心力量
### 核心命题
长期行动必须保护维持学习、组织和再行动所必需的核心力量，并通过补充、恢复和能力建设使其发展；保存不是消极不动，发展也不能以透支核心为代价。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《中国革命战争的战略问题》（1936年12月）对保存自己力量、争取主动和战争全局的分析，以及第二卷《论持久战》（1938年5月）对保存、补充与发展抗战力量的论述综合归纳；未作人民出版社1991年第二版逐字引文。核心能力清单、恢复预算和熔断线属于 C 级现代重构。

### 历史问题
革命战争和抗日战争在力量不利、过程长期的条件下，不能以一次行动耗尽继续抵抗和发展的基础，需要在具体行动、消耗、补充和组织发展之间保持全局联系。

### 关键变量
C 级现代转译：长期目标；核心力量构成；最低运行线；关键人员与能力；知识和信任；现金与物资；消耗率；补充率；恢复时间；学习增量；集中风险；替代性；保护、暂停和退出条件。

### 关系逻辑
历史命题处理的是战争力量能否持续存在并改变关系。C 级现代重构把核心力量定义为下一轮仍能判断、协作和行动的必要基础：适度投入可通过反馈和成果促进发展，但当消耗快于补充、关键能力高度集中或恢复期超过窗口时，继续投入会破坏长期可能性。

### 推演步骤
以下核心清单、最低线和恢复预算均为 C 级现代转译。

1. 从长期目标倒推不可缺失的人员、能力、资源、知识、信任与合法性。
2. 为每项核心力量记录当前存量、最低运行线、消耗、补充和恢复时间。
3. 检查计划是否形成单点依赖，是否把健康、安全、现金或关键关系透支为隐性成本。
4. 选择既能取得结果或学习、又不越过最低线的分段行动。
5. 把补充、休整、培训、文档化和接班机制列入计划，而非只安排产出。
6. 触及保护线、恢复能力丧失或核心目标失效时，暂停、缩小或退出。

### 适用条件
C 级现代转译：适用于过程持续时间较长，人员、资金、能力、知识或信任会被消耗并可得到补充，且下一轮行动依赖这些基础的团队与项目。

### 失效条件
C 级现代转译：当所谓核心只是维护负责人地位、保存会继续造成他人伤害、资源已低于安全运行线、恢复机制不存在，或法律和安全要求立即停止时，不能以保存发展之名延续行动。

### 常见误用
C 级现代转译：把不行动、不公开问题或保护既得小圈子称为保存力量；另一误用是用“成长”要求核心成员长期超负荷，忽略健康、信任、知识交接和现金的不可逆损耗。

### 关联模型
动态力量对比；时间作为战略变量；客观可能性与主观能动性；全局与局部；客观实际约束

### 现代转译
C 级现代转译：建立核心力量仪表：关键角色负荷、现金安全期、交付质量、知识冗余、团队信任和恢复周期；任何增长方案先证明这些基础不会跌破保护线，并同步安排补充与能力扩散。

### 转译边界
C 级现代转译：这是从特定革命战争生存与发展问题提炼的条件性持续能力框架，不是组织延续天然高于个人权利或保存现状总是正确的原则；历史军事、敌我和消灭语言不得直接转移到同事、家人、用户、合作方及普通竞争者关系，也不得以核心力量为由牺牲健康、安全、知情和自由退出。
