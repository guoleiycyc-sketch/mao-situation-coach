## Model: 客观实际约束
### 核心命题
任何判断和方案都必须受实际对象已有的条件、关系及其变化结果约束；愿望、身份和理论权威都不能替代事实。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《反对本本主义》（1930年5月）对从实际情况出发的论述，以及第一卷《实践论》（1937年7月）对认识来源和真理检验的论述综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
革命实践中曾出现以书本结论、上级指示或主观愿望代替对中国社会和具体地区的认识，导致路线与实际条件脱节的问题。

### 关键变量
C 级现代转译：分析对象与时间边界；已核实事实；资源与限制；参与者关系；主观目标；行动结果；事实的来源、时效和可信度。

### 关系逻辑
客观条件限定可行范围，参与者关系影响结果路径，实践结果反过来检验原有判断。目标可以引导选择，但不能改变尚未被行动改变的条件；当结果持续偏离预期时，应优先检查事实前提和关系判断。

### 推演步骤
以下事实分层、证伪问题与更新程序为 C 级现代转译，用于操作化上述命题。

1. 明确究竟在分析哪个对象、哪个时期和哪项结果。
2. 将已核实事实、转述、解释、预测和愿望分开记录。
3. 找出当前方案必须满足的资源、关系和制度条件。
4. 追问：什么可观察事实会推翻当前判断，是否已经出现？
5. 用最新结果更新事实表，再决定保留、缩小或撤回判断。

### 适用条件
C 级现代转译：适用于对象、时间和判断目标可以界定，并且至少有若干可核实事实或实践反馈的局面分析。

### 失效条件
C 级现代转译：当关键事实无法接近、信息被系统性操纵、对象正在剧烈变化而旧资料已失效，或问题本质上是价值与权利选择而非事实判断时，不能仅靠本模型得出结论。

### 常见误用
C 级现代转译：把眼前数字当作全部实际，忽略统计口径和参与者关系；例如只凭本月销售下降就断言产品没有需求。另一误用是用客观条件压制合理目标，把尚未尝试改变的限制说成不可改变。

### 关联模型
调查先于判断；实践—认识—再实践；全面联系地认识对象；客观可能性与主观能动性

### 现代转译
C 级现代转译：在产品、职业或组织判断中，先建立事实底图：哪些是可复核结果，哪些是解释，哪些是尚未验证的前提；方案只在这些条件允许的范围内暂时成立。

### 转译边界
C 级现代转译：这是从特定革命历史实践中提炼的条件性分析工具，不是超越时代的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以尊重客观条件为由忽视伦理、权利与安全。

## Model: 调查先于判断
### 核心命题
在对具体对象形成判断或提出处理办法以前，应先调查实际情况并取得具体材料；书本、权威和主观推断不能代替调查。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《反对本本主义》（1930年5月）关于调查与发言、解决问题关系的论述，以及第三卷《〈农村调查〉的序言和跋》（1941年3月、4月）对调查方法和材料作用的回顾综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
面对各地社会结构、土地关系和工作条件的差异，照搬书本或上级的一般结论会造成政策判断失真，因此需要通过实际调查认识具体地区与阶级关系。

### 关键变量
C 级现代转译：待决问题；调查对象；样本覆盖；一手观察与转述；时间范围；利益位置；相互冲突的材料；关键缺口；调查成本。

### 关系逻辑
具体对象的条件和关系存在差异，未经调查的判断缺少对实际情况的认识基础；调查使判断能够从具体材料和实际关系出发。C 级现代转译的操作化：用竞争解释限定调查问题，以材料覆盖调整确定程度，并优先获取最可能改变判断的信息。

### 推演步骤
以下竞争解释、证据门槛与证伪问题为 C 级现代转译，不作为原著中的固定调查程序。

1. 把待决判断改写为一个可以被事实回答的问题。
2. 列出至少两个竞争解释，以及各自预期会看到的证据。
3. 优先接触过程参与者、原始记录和实际结果，并标明转述链条。
4. 比较不同位置、不同时间和不同利益方的材料。
5. 追问：哪一种调查结果会推翻当前偏好的解释？
6. 到达当前决策所需证据门槛后形成暂时判断，同时保留缺口。

### 适用条件
C 级现代转译：适用于结论依赖具体人物、地区、流程、需求或资源情况，且存在可接触对象、记录或可观察结果的情形。

### 失效条件
C 级现代转译：当无法安全接近关键对象、调查会造成不可接受的伤害、样本被单一渠道完全控制，或必须立即处置明确的安全风险时，不能把继续调查当作延迟必要行动的理由。

### 常见误用
C 级现代转译：把调查变成支持既定结论的提问；例如只访谈最活跃的用户就宣布所有用户都需要某功能。也不能把无限收集资料当作不做判断，或用一次座谈替代长期行为与结果记录。

### 关联模型
客观实际约束；感性认识到理性认识；实践—认识—再实践；普遍性寓于特殊性

### 现代转译
C 级现代转译：在创业、管理或个人选择中，用访谈、行为记录、时间线和结果数据建立最小证据集；先调查最可能改变决定的信息，而不是追求表面完整的资料库。

### 转译边界
C 级现代转译：这是从特定社会调查与革命工作中提炼的条件性方法，不是任何时代都自动有效的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，调查也必须尊重隐私、知情同意与安全边界。

## Model: 感性认识到理性认识
### 核心命题
感性材料经过思考加工，由对事物现象和外部联系的认识上升为对其内部联系的理性认识；理性认识不能脱离感性材料自行产生。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第一卷《实践论》（1937年7月）关于认识由感性阶段发展到理性阶段及二者联系的论述归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
文章在抗日战争初期的理论教育语境中讨论认识发展，用以反对只凭局部经验的经验主义和脱离实际过程的教条主义。

### 关键变量
C 级现代转译：直接经验；材料数量与差异；观察口径；重复模式；对象间关系；概念与假设；反常材料；可检验预期。

### 关系逻辑
感性材料提供认识的内容，思考加工使认识由现象和外部联系深入到事物的内部联系；形成的理性认识又回到实践中发挥作用并接受发展。C 级现代转译的操作化：把理性认识改写成可检验解释和预测，主动检查反常材料，并用后续观察修正抽象。

### 推演步骤
以下可检验预期、反常材料检查与证伪问题为 C 级现代转译，用于提高抽象的可纠正性。

1. 收集来自不同时间、对象和位置的具体观察，不先合并成结论。
2. 比较哪些现象重复出现，哪些只在特定条件下出现。
3. 提出能够说明因果、制约或共同变化关系的解释。
4. 从解释推出下一次应当观察到什么，以及不应出现什么。
5. 追问：什么反常事实会推翻这一抽象，现有材料是否被它排除在外？

### 适用条件
C 级现代转译：适用于已经取得一定数量且来源可辨的经验材料，需要从事件描述上升为结构判断或工作假设的情形。

### 失效条件
C 级现代转译：当样本极少且同质、概念无法产生可观察预期、关键现象不可比较，或分析者无法接触反例时，暂不具备上升为稳定解释的条件。

### 常见误用
C 级现代转译：把第一次感受直接称为规律；例如听到三位客户抱怨就推断整个市场的核心需求。相反的误用是只谈抽象框架，却无法指出框架对应哪些具体材料。

### 关联模型
调查先于判断；实践—认识—再实践；一般理论具体化；普遍性寓于特殊性

### 现代转译
C 级现代转译：把访谈、事件记录和运营数据先当作现象层材料，再通过分组比较形成因果假设；每个抽象概念都要能回指材料，并能产生下一轮验证问题。

### 转译边界
C 级现代转译：这是对特定哲学与革命实践问题的条件性概括，不是保证认知必然进步的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不能用抽象分析抹去个体经验、少数情形或伦理限制。

## Model: 实践—认识—再实践
### 核心命题
认识应在实践结果中接受检验，并依据成功、失败和意外反馈修正后进入下一轮实践，而不是把一次结论固定化。

### 原文出处
证据等级：A 级；表达方式：有来源释义。依据第一卷《实践论》（1937年7月）关于实践产生认识、认识回到实践并在循环中发展的论述归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
文章围绕革命实践与认识的关系，批评脱离实际的教条主义和把局部经验绝对化的经验主义，说明理论判断需要在社会实践中形成并受其检验。

### 关键变量
C 级现代转译：初始判断；依赖前提；实践活动；预期结果；实际结果；反馈；外部干扰；修正后的认识；反馈时点；修正幅度；试验停止条件。

### 关系逻辑
认识指导实践，实践结果又检验和发展认识，修正后的认识再进入新的实践。C 级现代转译：反馈能够归因、过程得到记录会提高学习的可靠性，却不是一切学习发生的必要条件；非诊断性反馈仍可暴露未知，只是不能单独确认某项因果解释。

### 推演步骤
以下预期、观察窗口、证伪问题、记录与停止规则均为 C 级现代转译，用于形成可审计的低风险学习循环。

1. 写明当前判断、关键前提和对结果的具体预期。
2. 在本来就需要进行的实践或风险可控的行动中，选择能够产生区分性反馈的观察点。
3. 预先规定观察窗口、成功信号和停止条件。
4. 比较预期与实际，并排查执行偏差和外部干扰。
5. 追问：什么结果会推翻当前判断，而不是仅促使解释结果？
6. 修改假设或行动，再进入下一轮检验。

### 适用条件
C 级现代转译：适用于实践过程和结果可以观察，并允许依据反馈修正认识的项目、组织和个人决策；有意设计的试验还必须风险可控且可分阶段。

### 失效条件
C 级现代转译：当反馈无法区分竞争解释时，本模型不能把结果当作某项因果判断的确证，但仍可能产生线索。不可逆高风险、会伤害他人权益或受强制专业规范约束的行动，不得为了获取知识而被主动发起为试验；对必要实践、既有事件和观察材料仍可学习。

### 常见误用
C 级现代转译：把任何忙碌都叫实践，事前不写预期、事后只挑有利结果；例如营销活动失败后不断更换解释，却从不承认需求假设可能错误。另一误用是一次成功就宣布结论永久成立。

### 关联模型
客观实际约束；调查先于判断；感性认识到理性认识；条件转化

### 现代转译
C 级现代转译：把重要判断改写成低风险试验或必要实践中的观察方案，记录假设、动作、观察窗口和更新规则，以真实结果决定扩大、调整、停止或补充调查。

### 转译边界
C 级现代转译：这是从特定历史实践与认识论讨论中提炼的条件性循环，不是行动越多就越接近真理的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不得以试验之名突破安全、法律、专业和知情同意边界。

## Model: 一般理论具体化
### 核心命题
已经在一定范围形成的一般理论，只有转化为对新对象、阶段和条件的具体假设，并接受当地事实检验，才能用于判断；不能从抽象原则直接跳到结论。

### 原文出处
证据等级：B 级；表达方式：有来源释义。依据第一卷《反对本本主义》（1930年5月）对照搬书本的批评、第一卷《矛盾论》（1937年8月）对具体事物矛盾特殊性的分析，以及第三卷《改造我们的学习》（1941年5月19日）关于研究实际问题的论述综合归纳；未作人民出版社1991年第二版逐字引文。

### 历史问题
中国革命在不同地区、时期和社会关系中面临不同任务，机械搬用外来经验或一般公式，无法说明当地力量结构与实际进程。

### 关键变量
C 级现代转译：既有一般命题；原命题成立条件；新对象；历史阶段；当地关系结构；相同点与差异点；可观察指标；修正规则。

### 关系逻辑
C 级现代转译的模型分工：本卡从一个既有的一般理论出发，向下检查它在新对象中的成立条件；它不负责从多个特殊对象向上抽取共同关系。具体条件决定既有关系是否存在、以何种形式出现以及作用强弱；差异若触及必要条件，就必须修改应用结论。

### 推演步骤
以下条件匹配、可检验假设、证伪问题与修正规则为 C 级现代转译，用于检验既有理论的新情境应用。

1. 说明一般理论究竟声称哪些变量存在何种关系。
2. 列出该关系成立所需的对象、阶段和边界条件。
3. 调查当前情境与原条件的相同点、差异点和缺失信息。
4. 把理论改写成针对当前对象的可检验假设。
5. 追问：哪项当地事实会推翻这次具体化，而不是仅推翻理论的某种表述？
6. 根据验证结果限定、修订或放弃应用。

### 适用条件
C 级现代转译：适用于借助已有理论、行业经验或历史案例理解新情境，并且能够明确比较条件和取得当地证据的情形。

### 失效条件
C 级现代转译：当理论本身不可证伪、原始成立条件不清、当前对象缺乏可比性，或使用者只想用权威名称为既定决定背书时，本模型不能生成可靠判断。

### 常见误用
C 级现代转译：把别处增长方法原样复制到用户、渠道和成本结构不同的业务；也可能因存在任何差异就拒绝全部一般经验，而不分析哪些关系仍然成立。

### 关联模型
客观实际约束；调查先于判断；普遍性寓于特殊性；发展阶段

### 现代转译
C 级现代转译：采用管理框架或案例前，先写出它依赖的机制，再用本地用户、资源、制度和阶段信息进行条件匹配，形成仅对当前场景负责的假设。

### 转译边界
C 级现代转译：这是从特定反教条与革命认识实践中提炼的条件性方法，不是任何理论都能普遍落地的永恒规律；不得把战争、敌我或消灭语言直接套入同事、家人、用户和普通竞争者关系，也不能用具体化之名任意改写理论、回避证伪或侵犯他人权益。
